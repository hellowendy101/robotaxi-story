Robotaxi Crashes and DC - scrolling web story (PPOL 5205 Concept Showcase)

1. Put two photos in images/: opening.jpg and crosswalk.jpg.
2. Run the "export the numbers used by the web story" cell in the analysis notebook; it rewrites data.js with exact numbers.
3. In story.js, fill in CONFIG.author (and CONFIG.explorerUrl once the Streamlit explorer is online).
4. Open index.html in Chrome. The maps need an internet connection (D3 and the U.S. outline load from jsDelivr).
